# 超速-TSL

## 卓越救援疾行者外壳

外壳型号：救援
外壳风格：超速-TSL
外壳系列：奥克斯

理论科学实验室[TSL],一个汇聚顶尖思想家的独特团体,他们借助疾行者推进众多科研议程。为此,TSL 开始研发独特的高端外壳,以支持那些愿意突破可能性极限的疾行者。熟知内情的疾行者都预计 TSL 会率先出现在天仓五。TSL 将自己视作未来主义者和规则颠覆者,他们的超速外壳已在天仓五IV掀起风浪,而这可能只是他们影响/冲击/操控现状的开端。
