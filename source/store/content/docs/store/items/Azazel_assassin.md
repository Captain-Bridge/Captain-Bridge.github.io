# 阿撒兹勒

## 豪华刺客疾行者外壳

外壳型号：刺客
外壳风格：阿撒兹勒
外壳系列：沃伊德
<span style="color: rgb(26, 122, 215);">一一一一一一一一一一一一一一一一一</span>

第四恶魔。神话。传奇。疾行者虽然务实,但并不至于完全忽视迷信和传闻。阿撒兹勒便是一个变为现实的传闻。传说中的十三个恶魔的故事据说起源于神经转移技术的早期,当时似乎有一小批人类试验对象出现“狂暴“一一十三颗心智因尚未验证的外壳技术而被撕裂,陷入疯狂。为推进这项科学而记录实验的研究者们,将十三个迷失的灵魂以神话中的恶魔命名。很久之后,疾行者们挖掘出这些古老的研究记录,并以受难者的名字作为呼号,来纪念他们的牺牲。阿撒兹勒只是其中之一,刺客用这个名字映衬自身幽灵般的存在。
