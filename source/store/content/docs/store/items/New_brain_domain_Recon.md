# 新脑域

## 卓越侦察疾行者外壳

外壳型号：侦察
外壳风格：新脑域
外壳系列：布莱克伯德
<span style="color: rgb(26, 122, 215);">一一一一一一一一一一一一一一一一一</span>

新黑色是一支疾行者团队。
新黑色是脑域和暗窟和极点和行轨。
新黑色是无所不见的黑暗。
新黑色是夜晚的观察者,审判所有进入其视线之人。
脑域是他们的法官与陪审团一一神经偏差者接入侦察外壳,追踪瞬时意识的阈下残留。
脑域是暴力权威一一识别敌对意图并将其标记为强制驱逐或彻底清除对象。
脑域在等待一一命运的裁决者。
脑域在观察一一从未停止。
