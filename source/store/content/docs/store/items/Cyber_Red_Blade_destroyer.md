# 赛博红刃

## 卓越毁灭者疾行者外壳

外壳型号：毁灭者
外壳风格：赛博红刃
外壳系列：洛卡斯
<span style="color: rgb(26, 122, 215);">一一一一一一一一一一一一一一一一一</span>

赛博红刃曾是一支臭名昭著的自由杀手团队,由前 UESC 特种部队士兵组成,他们在外壳战遭到星际条约禁止后投入了私人行动。在“千人死亡之夜“及随后UESC 对该队伍进行突袭和镇压后,他们成为了整个太阳系的新闻头条。只有少数成员逃过了神经删除或抓捕,但自事件后便杳无踪影。

起初,疾行者报告在天仓五附近发现赛博红刃毁灭者时,人们以为这只是吓唬新手的恐吓手段。在马拉松号的阴影之中,真相与谣言往往难以区分。然而,关于穿戴赛博红刃标志性数字夜血迷彩外壳的疾行者目击报告越来越多,预示着新卡斯卡迪亚废弃区域的野蛮战术正在升级。
