# 迷雾杀机

## 豪华刺客疾行者外壳

外壳型号：刺客
外壳风格：迷雾杀机
外壳系列：沃伊德
<span style="color: rgb(26, 122, 215);">一一一一一一一一一一一一一一一一一</span>

“迷雾杀机“是官方秘密疾行者行动末期用于一支秘密 UESC 疾行者部队的代号。根据机密文件显示,这支部队已知的部署只有在月球上成功进行的反叛乱行动,以及一次在暴力领土争端中清剿残余势力的短期环带巡逻。随后,这支部队在反战斗外壳部署法律颁布之前就被解散了。他们提前“退役“的原因在所有公开档案中均被隐藏,但不久之后,迷雾杀机外壳及图纸便开始在疾行者圈子中流转。这支部队究竟是主动叛变,还是像许多其他案例一样被盗用了技术,目前仍不得而知。
