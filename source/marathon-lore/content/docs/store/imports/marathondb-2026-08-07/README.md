# MarathonDB 商店素材候选（2026-08-07）

本目录保存从 MarathonDB 公开页面及其公开资源接口下载的第一批候选素材，仅供人工核对和后续整理。

## 文件约定

- `thumbnail.webp`：小图标候选。
- `card.webp`：目录封面候选，原始比例约为 `1:2`。
- `full.webp`：详情大图候选。
- `sources.json`：名称、职业、价格、来源页、原始资源地址及待核验信息。

## 使用前检查

1. 核对游戏内中文名、价格、上架时间和组合包归属。
2. 确认图片裁切是否适合本站目录与详情视图。
3. 确认 Bungie 与 MarathonDB 对图片转载、署名和再发布的要求。
4. 通过检查后再把选定文件移动到正式商店素材目录，并更新 `store.json`。

MarathonDB 明确标注其为非 Bungie 官方站点。本批次没有把候选素材自动写入正式商店数据。
