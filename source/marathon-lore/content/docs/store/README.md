# 商店布局配置

商店数据位于 `source/marathon-lore/content/modules/store.json`。

## 目录藏品

目录在桌面端以每行四个正方形为基础网格。每个 `items` 条目可以设置：

```json
"layout": {
  "size": 1
}
```

- `size: 1`：占一个方块。
- `size: 2, direction: "horizontal"`：横向占两个方块。
- `size: 2, direction: "vertical"`：纵向占两个方块。
- `imageFit: "contain"`：完整显示封面，可能留空边。
- `imageFit: "cover"`：封面铺满卡片，边缘可能被裁切。

目录卡片的名称、分类和价格覆盖在封面底部，封面容器本身严格保持基础网格比例：单格为 `1:1`，横向双格为 `2:1`，纵向双格为 `1:2`。

条目顺序就是网格放置顺序；网格会自动紧密填补可用空位。

## 组合包

- 设置 `featured: true` 的组合包是主推项，桌面端横跨整行并保持 `12:5` 封面比例。
- 其余组合包使用 `7:10` 的竖版封面，桌面端每行排列三个。
- 当主推项和普通组合包同时存在时，网格会按首屏剩余高度共同缩放两行，比例不变但尽量完整显示在一个屏幕内。
- 建议配置一个主推组合包和六个普通组合包；超出的普通组合包会继续按相同规则向下排列。
- 如果没有设置主推项，第一个组合包会自动成为主推项。
- 如果多个组合包设置了 `featured: true`，只采用第一个并在控制台输出警告。

平板端基础网格会降为两列，手机端降为一列，避免卡片和文字发生挤压。
