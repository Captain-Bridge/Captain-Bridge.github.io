# 青冥

## 豪华救援疾行者外壳

外壳型号：救援
外壳风格：青冥
外壳系列：奥克斯
<span style="color: rgb(26, 122, 215);">一一一一一一一一一一一一一一一一一</span>

青冥象征疾行者生活中无形、流动的现实,是对死亡的抗衡。青冥不受戒律约束,也不追求群体归属。没有集会、说教或条条框框的信仰,只有一个最基本的认知：

生命+技术+野心+抗争意志=永恒

这既非威胁,也非承诺,仅仅是对一种恒定的承认,而疾行者的生活使这种恒定愈加稳固。它是反宿命论。它是最纯粹的希望。它诞生于暴力,并一次又一次重生,为千变万化的可能注入新生。

它是一种接受,也是一种在面对必然时仍茁壮生长的意志。

青冥就是生命。
