Marathon Update 1.1.5.5

The one about the UESC Manifests

Marathon Dev Team August 25, 2026
updates145 words1 min read

Ordnance Heist

  • Fixed an issue where UESC Manifests were not shared among crew upon exfil.
    • If you have not already claimed it, players should check their mailbox for the 150 Manifests we had previously sent out while this issue was active.
  • Increased the number of Firestorm Locker Keys granted upon completion of a key template, up to 3 from 1.
  • Updated Firestorm Arms Locker loot.
    • Increased the number of rolls for implants and cores, with a higher chance of these items dropping at Prestige rarity.
    • To make room for these increases, slightly reduced weapon chip and consumable item count.
  • Dev Note: The above two changes originally went live on Friday, 8/21.

General

  • Fixed an issue where opening the Hidden Cache in Cryo Archive would continuously grant XP and MIDA reputation.
    • This action, as well as any others that were temporarily disabled, have now been re-enabled.

军械盗劫

  • 修复了撤离后UESC清单未在团队成员之间共享的问题。
    • 尚未领取的玩家请前往邮箱查收我们此前在该问题存在期间发放的150份UESC清单。
  • 完成钥匙模板后获得的烈焰风暴武器柜钥匙数量由1把增加至3把。
  • 更新了烈焰风暴武器柜的战利品。
    • 增加了植入物和核心的掉落次数，并提高了尊享稀有度的掉落概率。
    • 为了给这些增长留出空间，我们略微下调了武器芯片和消耗品的数量。
  • 开发者说明：上述两项改动已于8月22日（星期六）上线。

综合

  • 修复了在低温档案室开启隐藏储藏箱时会持续获得经验值和米达声望的问题。
    • 该操作及其他此前暂时停用的功能现已全部恢复。
