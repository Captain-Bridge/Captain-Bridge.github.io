Marathon Update 1.1.9

The one about Rook's inventory

Marathon Dev Team September 1, 2026
updates314 words1 min read

Item Economy

C.A.R.R.I Armory Update

  • Added a Superior Shield Implant and a Superior Backpack.
    • These will be able to be acquired 3x per week.
  • Reduced CyberAcme Commendations cost for some items.
    • Deluxe Backpack: 20 -> 15.
    • Deluxe Shield Implant: 12 -> 10.
    • Deluxe Key Template: 40 -> 30.
    • Superior Key Template: 75 -> 50.

Combat

Rook Inventory Update

  • Added items to Rook’s inventory:
    • Compromised Sneak Pack.
    • 2x Claymores.
    • 1x Depleted Self Revive.
    • 1x Signal Jammer.
  • These updates will last until the end of Season 2.

Mods

  • Fixed an issue where the Full-Auto Selector mod incorrectly stated that it increased rate of fire.

User Interface and Experience

  • Fixed a visual issue with the Threat indicator text when selecting a Ranked mode.
  • Fixed an issue where the audible invite sent notice and player joined notice would not always play when inviting a player.

Contracts

  • Fixed an issue in Return on Investment 4/5 where objectives could become un-interactable if players walked away while mid-completion.
  • Fixed an issue in Unsanctioned Hostilities 5/5 where the contract would not progress when acquiring quest items from other players.

Codex

  • Made additional updates to prevent players from getting into a state where they have completed a Codex challenge but not get credit for that completion.
  • Fixed an issue where players who reached Level 100 in Season 1 but did not claim the Century Runner emblem before Season 2 launched could not claim it.

Zones

  • Sponsored Night Marsh returns.

Cryo Archive

  • Fixed an issue allowing players to get outside of the playable map area.
  • Fixed an issue where the door in and out of the Compiler fight could incorrectly close.

Localization

  • Fixed several issues with text getting cut off in Russian.

General

  • Fixed an issue where parts of the Acid Abyss Thief skin would show in the player view when using the KKV-9SD.
  • Fixed a minor typo in the Thief Weaverunner Shell description.

物品经济

C.A.R.R.I军械库更新

  • 新增一个卓越护盾植入物和一个卓越背包。
    • 每周可获取3次。
  • 降低了部分物品需要消耗的赛博艾克米嘉奖。
    • 豪华背包：20 -> 15。
    • 豪华护盾植入物：12 -> 10。
    • 豪华钥匙模板：40 -> 30。
    • 卓越钥匙模板：75 -> 50。

战斗

鲁克物品栏更新

  • 鲁克的物品栏新增以下物品：
    • 受损的潜行包。
    • 2x阔刀地雷。
    • 1x耗尽的自我复活。
    • 1x信号干扰器。
  • 更新将持续至第2赛季结束。

模组

  • 修复了全自动切换器模组可提高射速的错误说明。

用户界面和体验

  • 修复了选择排名模式时，威胁指示器文本显示异常的问题。
  • 修复了邀请玩家时，邀请已发送和玩家已加入的提示音有时不会播放的问题。

合约

  • 修复了投资回报率[4/5]中，玩家在完成目标途中离开，会导致目标无法交互的问题。
  • 修复了无规冲突[5/5]中，从其他玩家处获取任务物品后，合约无法继续推进的问题。

百科

  • 进行了额外更新，避免玩家完成百科挑战后无法获得信用点。
  • 修复了在第1赛季达到100级但未在第2赛季开始前领取百年老手徽标的玩家，此后无法领取该徽标的问题。

区域

  • 赞助夜间沼泽回归。

低温档案室

  • 修复了玩家可以离开可游玩地图区域的问题。
  • 修复了编译者战斗区域出入口的门可能错误关闭的问题。

本地化

  • 修复了多个俄语文本显示不完整的问题。

综合

  • 修复了使用KKV-9SD时，玩家视野中会出现酸蚀深渊盗贼皮肤的部分模型的问题。
  • 修复了盗贼织行者外壳说明中的一处小错误。
